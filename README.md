# Data-to-Credit

## 🎓 Parcours de Certification : Data-to-Credit

Bienvenue dans votre parcours de formation ! Ce programme est divisé en deux étapes clés pour vous transformer en expert de la donnée financière.

---

## 🟢 Étape 1 : Fondations et Qualité (Bloc 1)
*Objectif : Apprendre à collecter, nettoyer et sécuriser les données pour créer une base de confiance.*

[**Accéder aux supports sur GitHub**](https://github.com/wanzo-academy/bloc1)

| Module | Ce que vous allez apprendre | Ce que vous allez réaliser |
| :--- | :--- | :--- |
| **Data & IA** | Comprendre pourquoi la donnée donne accès au crédit. | Une stratégie des données pour votre projet. |
| **Mathématiques** | Les calculs essentiels pour le scoring financier. | Un simulateur de score de crédit. |
| **Statistiques** | Analyser les tendances et détecter les erreurs. | Un rapport avec vos indicateurs clés (KPI). |
| **Python Débutant** | Automatiser vos premières tâches avec du code. | Un carnet (Notebook) de fonctions utiles. |
| **Bases de données** | Structurer la saisie des ventes et des stocks. | Une base de données prête à l'emploi. |
| **Qualité (FEC)** | Nettoyer les historiques et corriger les erreurs. | Un plan d'action pour des données propres. |
| **Architecture** | Créer des tableaux de bord pour le quotidien. | Un modèle de flux de données documenté. |
| **Audit & Gouvernance** | Rendre les données infalsifiables et auditables. | Une checklist pour être prêt face à la banque. |

**Total : 165 heures de pratique**

---

## 🔵 Étape 2 : Analyse et Intelligence (Bloc 2)
*Objectif : Analyser, automatiser et prédire pour faciliter la prise de décision.*

[**Accéder aux supports sur GitHub**](https://github.com/wanzo-academy/bloc2)

| Module | Ce que vous allez apprendre | Ce que vous allez réaliser |
| :--- | :--- | :--- |
| **Python Avancé** | Manipuler de gros volumes de données (Pandas). | Un outil d'analyse dynamique. |
| **SQL Master** | Extraire précisément les infos dont vous avez besoin. | Des scripts d'extraction automatique. |
| **Excel Expert** | Créer des scénarios financiers et de trésorerie. | Un modèle financier complet sous Excel. |
| **Visualisation** | Transformer les chiffres en graphiques clairs. | Un tableau de bord (Dashboard) interactif. |
| **Reporting Auto** | Automatiser la comptabilité et les rapports. | Un système de rapport de trésorerie auto. |
| **IA & Saisie** | Utiliser l'IA pour saisir les données sans effort. | Une routine de saisie intelligente. |
| **Scoring Crédit** | Prédire la capacité de remboursement. | Un rapport de recommandation de crédit. |

**Total : 115 heures de spécialisation**
